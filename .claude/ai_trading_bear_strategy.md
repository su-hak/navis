# AI 자동매매 시스템 하락장 대응 전략 기획서

## 🎯 목적

상승장에만 작동하던 기존 자동매매 시스템을\
하락장에서도 수익을 창출하는 양방향 트레이딩 시스템으로 확장

------------------------------------------------------------------------

# 1. 문제 정의

현재 시스템: - 매수 전략만 존재 - 하락장에서는 거래 없음 - 현금 100%
대기

👉 결과: - 기회비용 발생 - 수익 구조 불완전

------------------------------------------------------------------------

# 2. 해결 전략 (핵심 방향)

## 적용 전략 조합

-   A: 시장 국면 감지 (필수)
-   B: 인버스 ETF 전략 (수익화)
-   D: 섹터 로테이션 (안정성)

------------------------------------------------------------------------

# 3. 시장 국면 감지 모듈

## 신규 모듈

market_regime_detector

------------------------------------------------------------------------

## 로직

``` python
if SPY > SMA50 and QQQ > SMA50:
    regime = "BULL"
elif SPY < SMA50 and QQQ < SMA50:
    regime = "BEAR"
else:
    regime = "NEUTRAL"
```

------------------------------------------------------------------------

## 출력

``` json
{
  "regime": "BEAR",
  "confidence": 0.82
}
```

------------------------------------------------------------------------

# 4. 전략 분기 시스템

``` python
if regime == "BULL":
    run_long_strategy()
elif regime == "BEAR":
    run_bear_strategy()
else:
    reduce_position()
```

------------------------------------------------------------------------

# 5. 하락장 전략

## 5.1 인버스 ETF 전략

### 대상

-   SQQQ
-   SPXU

------------------------------------------------------------------------

### 매수 조건

``` python
if regime == "BEAR" and QQQ < SMA20:
    buy("SQQQ")
```

------------------------------------------------------------------------

### 매도 조건

-   +5% 익절
-   -2% 손절
-   시장 전환 시 청산

------------------------------------------------------------------------

### 리스크 제한

-   최대 포지션 20%
-   하루 2회 제한

------------------------------------------------------------------------

## 5.2 섹터 로테이션 전략

### 대상 섹터

-   헬스케어
-   필수 소비재
-   유틸리티

------------------------------------------------------------------------

### 로직

``` python
if regime == "BEAR":
    select_defensive_stocks()
```

------------------------------------------------------------------------

### 예시

-   JNJ
-   PG
-   XLU

------------------------------------------------------------------------
