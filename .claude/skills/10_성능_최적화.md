## 📊 DB 인덱스 최적화

### Index가 필요한 경우
- ✅ WHERE 절에 자주 사용되는 컬럼
- ✅ JOIN에 사용되는 컬럼
- ✅ ORDER BY에 사용되는 컬럼
- ✅ 외래키 (Foreign Key)

### Index 추가 패턴
```typescript
// 단일 인덱스
@Entity('users')
export class User {
  @Column()
  @Index() // 이메일 조회가 빈번할 때
  email: string;
}

// 복합 인덱스
@Entity('ab_test_events')
@Index('idx_device_variant', ['deviceId', 'variant'])
@Index('idx_variant_eventType', ['variant', 'eventType'])
export class AbTestEvent {
  @Column({ name: 'device_id' })
  deviceId: string;

  @Column()
  variant: string;

  @Column({ name: 'event_type' })
  eventType: string;
}

// Unique Index
@Entity('users')
export class User {
  @Column({ unique: true }) // 자동으로 unique index 생성
  email: string;
}
```

### Index 성능 확인
```sql
-- MySQL
EXPLAIN SELECT * FROM users WHERE email = 'test@test.com';

-- Index 사용 여부 확인
-- type: ref → Index 사용
-- type: ALL → Full Table Scan (Index 없음)
```

## 🔄 N+1 문제 해결

### N+1 문제란?
```typescript
// ❌ N+1 문제 발생
const users = await this.userRepository.find(); // 1번 쿼리
for (const user of users) {
  const payments = await this.paymentRepository.find({
    where: { user: { id: user.id } }
  }); // N번 쿼리 (users 수만큼)
}
```

### 해결책 1: Eager Loading
```typescript
@Entity('users')
export class User {
  @OneToMany(() => Payment, (payment) => payment.user, { eager: true })
  payments: Payment[];
}

// 사용 시
const users = await this.userRepository.find(); // 1번 쿼리 (JOIN)
```

### 해결책 2: Relations 옵션
```typescript
// ✅ 1번 쿼리로 해결 (LEFT JOIN)
const users = await this.userRepository.find({
  relations: ['payments'],
});
```

### 해결책 3: QueryBuilder
```typescript
const users = await this.userRepository
  .createQueryBuilder('user')
  .leftJoinAndSelect('user.payments', 'payment')
  .getMany();
```

## 💾 Redis 캐싱 (선택)

### 패키지 설치
```bash
npm install cache-manager cache-manager-redis-store redis
npm install -D @types/cache-manager
```

### app.module.ts 설정
```typescript
import { CacheModule } from '@nestjs/cache-manager';
import * as redisStore from 'cache-manager-redis-store';

@Module({
  imports: [
    CacheModule.register({
      isGlobal: true,
      store: redisStore,
      host: process.env.REDIS_HOST || 'localhost',
      port: process.env.REDIS_PORT || 6379,
      ttl: 60, // 기본 TTL 60초
    }),
  ],
})
```

### Service에서 사용
```typescript
import { Injectable, Inject } from '@nestjs/common';
import { CACHE_MANAGER } from '@nestjs/cache-manager';
import { Cache } from 'cache-manager';

@Injectable()
export class StocksService {
  constructor(
    @Inject(CACHE_MANAGER)
    private cacheManager: Cache,
  ) {}

  async getStockData(symbol: string) {
    // 캐시 확인
    const cacheKey = `stock:${symbol}`;
    const cached = await this.cacheManager.get(cacheKey);
    if (cached) {
      return cached;
    }

    // API 호출
    const data = await this.fetchFromAPI(symbol);

    // 캐시 저장 (60초)
    await this.cacheManager.set(cacheKey, data, 60);

    return data;
  }
}
```

## 📄 페이지네이션

### 기본 패턴
```typescript
async findPaginated(page: number = 1, limit: number = 10) {
  const [items, total] = await this.repository.findAndCount({
    skip: (page - 1) * limit,
    take: limit,
    order: { createdAt: 'DESC' },
  });

  return {
    data: items,
    total,
    page,
    lastPage: Math.ceil(total / limit),
  };
}
```

### Controller에서 사용
```typescript
@Get()
async getItems(@Query('page') page: number = 1, @Query('limit') limit: number = 10) {
  return this.service.findPaginated(page, limit);
}
```
