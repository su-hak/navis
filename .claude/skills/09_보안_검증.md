## 🛡️ DTO Validation 패턴

### ValidationPipe 설정 (main.ts)
```typescript
import { ValidationPipe } from '@nestjs/common';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.useGlobalPipes(new ValidationPipe({
    whitelist: true,        // DTO에 없는 속성 제거
    forbidNonWhitelisted: true, // DTO에 없는 속성 전송 시 에러
    transform: true,        // 타입 자동 변환 (string → number 등)
  }));

  await app.listen(3000);
}
```

### DTO 작성 패턴
```typescript
import { IsEmail, IsString, MinLength, MaxLength, IsOptional, IsNumber, Min, Max } from 'class-validator';

export class RegisterDto {
  @IsEmail({}, { message: '올바른 이메일 형식이 아닙니다.' })
  email: string;

  @IsString()
  @MinLength(6, { message: '비밀번호는 최소 6자 이상이어야 합니다.' })
  @MaxLength(100)
  password: string;

  @IsString()
  @MinLength(2)
  @MaxLength(50)
  name: string;
}

export class CreatePostDto {
  @IsString()
  @MinLength(1)
  title: string;

  @IsString()
  @IsOptional() // 선택 필드
  content?: string;

  @IsNumber()
  @Min(0)
  @Max(100)
  rating: number;
}
```

## 🔐 비밀번호 보안

### bcrypt 해싱 (10 rounds)
```typescript
import * as bcrypt from 'bcrypt';

// 회원가입 시
const hashedPassword = await bcrypt.hash(password, 10);

// 로그인 시
const isPasswordValid = await bcrypt.compare(password, user.password);
if (!isPasswordValid) {
  throw new UnauthorizedException('비밀번호가 일치하지 않습니다.');
}
```

### 비밀번호 정책
- ✅ 최소 6자 이상
- ✅ bcrypt 10 rounds (권장)
- ❌ 평문 저장 절대 금지
- ❌ MD5, SHA1 사용 금지

## 🔑 JWT 보안

### Access Token 설정
```typescript
JwtModule.registerAsync({
  useFactory: async (configService: ConfigService) => ({
    secret: configService.get<string>('JWT_SECRET'),
    signOptions: { expiresIn: '15m' }, // 15분 (짧게)
  }),
})
```

### Refresh Token 설정
```typescript
const refreshToken = this.jwtService.sign(payload, {
  secret: this.configService.get<string>('JWT_REFRESH_SECRET'),
  expiresIn: '7d', // 7일
});
```

### JWT_SECRET 생성
```bash
# .env
JWT_SECRET=$(openssl rand -base64 64)
JWT_REFRESH_SECRET=$(openssl rand -base64 64)
```

## 🚫 SQL Injection 방어

### TypeORM Repository 사용 (자동 방어)
```typescript
// ✅ 안전: TypeORM이 자동으로 이스케이프
await this.userRepository.findOne({ where: { email } });

// ❌ 위험: Raw Query
await this.userRepository.query(`SELECT * FROM users WHERE email = '${email}'`);

// ✅ 안전: Raw Query with Parameters
await this.userRepository.query(
  'SELECT * FROM users WHERE email = ?',
  [email]
);
```

## 🔒 XSS 방어

### class-transformer 사용
```typescript
import { Exclude, Expose } from 'class-transformer';

export class UserResponseDto {
  @Expose()
  id: string;

  @Expose()
  email: string;

  @Exclude() // 비밀번호는 응답에서 제외
  password: string;
}
```

### 응답 시 변환
```typescript
import { classToPlain } from 'class-transformer';

@Get('profile')
getProfile(@Request() req) {
  return classToPlain(new UserResponseDto(req.user));
}
```

## ⏱️ Rate Limiting (선택)

### 패키지 설치
```bash
npm install @nestjs/throttler
```

### app.module.ts에 추가
```typescript
import { ThrottlerModule } from '@nestjs/throttler';

@Module({
  imports: [
    ThrottlerModule.forRoot({
      ttl: 60,    // 60초 동안
      limit: 10,  // 최대 10개 요청
    }),
  ],
})
```

### Controller에 적용
```typescript
import { Throttle } from '@nestjs/throttler';

@Controller('api/auth')
export class AuthController {
  @Post('login')
  @Throttle(5, 60) // 60초에 최대 5번
  async login(@Body() loginDto: LoginDto) {
    // ...
  }
}
```
