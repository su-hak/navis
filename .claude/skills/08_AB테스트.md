## 🔑 핵심 패턴: 해시 기반 일관된 그룹 배정

### 문제
- 랜덤 배정 시 같은 디바이스가 다른 그룹에 배정될 수 있음
- DB 조회 없이 일관된 배정 필요

### 해결책: 해시 기반 배정
```typescript
async getVariant(deviceId: string): Promise<string> {
  // 1. 이미 배정된 적 있는지 확인
  const existing = await this.assignmentRepo.findOne({ where: { deviceId } });
  if (existing) {
    return existing.variant;
  }

  // 2. 해시 기반 일관된 분배 (같은 deviceId는 항상 같은 그룹)
  const hash = this.hashString(deviceId);
  const bucket = hash % 100;

  let variant: string;
  if (bucket < 33) {
    variant = 'A';        // 0~32: A 그룹 (33%)
  } else if (bucket < 66) {
    variant = 'B';        // 33~65: B 그룹 (33%)
  } else {
    variant = 'C';        // 66~99: C 그룹 (34%)
  }

  // 3. DB에 저장
  const assignment = this.assignmentRepo.create({ deviceId, variant });
  await this.assignmentRepo.save(assignment);

  console.log(`🎲 새 배정: ${deviceId} → 그룹 ${variant}`);

  return variant;
}

// 해시 함수 (일관된 분배)
private hashString(str: string): number {
  let hash = 0;
  for (let i = 0; i < str.length; i++) {
    hash = ((hash << 5) - hash) + str.charCodeAt(i);
    hash = hash & hash; // Convert to 32bit integer
  }
  return Math.abs(hash);
}
```

**핵심 포인트**:
- ✅ 같은 deviceId는 항상 같은 hash 값 → 일관된 그룹 배정
- ✅ DB 조회 없이도 배정 가능 (hash 기반)
- ✅ A/B/C 그룹 비율 조정 가능 (bucket 범위 변경)

## 📈 이벤트 로깅

### logEvent 메서드
```typescript
async logEvent(logEventDto: LogEventDto): Promise<void> {
  const { deviceId, eventType, metadata } = logEventDto;

  // 해당 디바이스의 variant 가져오기
  const assignment = await this.assignmentRepo.findOne({ where: { deviceId } });

  if (!assignment) {
    console.warn(`⚠️ 배정되지 않은 디바이스: ${deviceId}`);
    return; // 배정되지 않은 디바이스는 무시
  }

  // 이벤트 저장
  const event = this.eventRepo.create({
    deviceId,
    variant: assignment.variant,
    eventType,
    metadata,
  });
  await this.eventRepo.save(event);

  console.log(`📊 이벤트 기록: ${deviceId} (그룹 ${assignment.variant}) - ${eventType}`);
}
```

## 📊 통계 조회 (관리자용)

### getStats 메서드
```typescript
async getStats() {
  // 그룹별 배정 수
  const assignments = await this.assignmentRepo
    .createQueryBuilder('assignment')
    .select('assignment.variant', 'variant')
    .addSelect('COUNT(*)', 'count')
    .groupBy('assignment.variant')
    .getRawMany();

  // 그룹별 이벤트 수
  const events = await this.eventRepo
    .createQueryBuilder('event')
    .select('event.variant', 'variant')
    .addSelect('event.eventType', 'eventType')
    .addSelect('COUNT(*)', 'count')
    .groupBy('event.variant, event.eventType')
    .getRawMany();

  return {
    assignments,
    events,
    totalUsers: await this.assignmentRepo.count(),
    totalEvents: await this.eventRepo.count(),
  };
}
```

## 🎮 AbTest Controller

### ab-test.controller.ts
```typescript
import { Controller, Get, Post, Query, Body } from '@nestjs/common';
import { AbTestService } from './ab-test.service';
import { LogEventDto } from './dto/log-event.dto';

@Controller('api/ab-test')
export class AbTestController {
  constructor(private readonly abTestService: AbTestService) {}

  // 그룹 배정 받기
  @Get('variant')
  async getVariant(@Query('deviceId') deviceId: string) {
    if (!deviceId) {
      return { success: false, message: 'deviceId is required' };
    }

    const variant = await this.abTestService.getVariant(deviceId);

    return {
      success: true,
      variant,
      timestamp: new Date(),
    };
  }

  // 이벤트 기록
  @Post('event')
  async logEvent(@Body() logEventDto: LogEventDto) {
    await this.abTestService.logEvent(logEventDto);

    return {
      success: true,
      message: 'Event logged successfully',
    };
  }

  // 통계 조회 (관리자용)
  @Get('stats')
  async getStats() {
    const stats = await this.abTestService.getStats();

    return {
      success: true,
      data: stats,
    };
  }
}
```
