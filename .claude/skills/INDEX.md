# 📚 NestJS Backend Skills 가이드

---

## 🎯 프로젝트 핵심 원칙

- ✅ **Mock 데이터 절대 금지** → 모든 테스트는 실제 DB 연결
- ✅ **일관된 구조 유지** → 구독/광고/사용자 시스템은 동일한 패턴
- ✅ **근본적 해결** → 파일 제거는 마지막 수단
- ✅ **투명성** → 자동 커밋, 한글 메시지
- ✅ **Push 절대 금지**
