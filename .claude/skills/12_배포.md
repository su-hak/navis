# 12. 배포 및 트러블슈팅

> **목적**: Railway 배포, 환경변수 설정, 프로덕션 체크리스트

---

## 🚀 Railway 배포

### 1. Railway 프로젝트 생성
1. [Railway](https://railway.app/) 접속 및 로그인
2. "New Project" 클릭
3. "Deploy from GitHub repo" 선택
4. 프로젝트 선택

### 2. MySQL 데이터베이스 추가
1. "New" → "Database" → "Add MySQL"
2. 자동으로 환경변수 설정됨:
   - `MYSQLHOST`
   - `MYSQLPORT`
   - `MYSQLUSER`
   - `MYSQLPASSWORD`
   - `MYSQLDATABASE`

### 3. 환경변수 설정
Railway 프로젝트 → Variables 탭에서 추가:

```bash
# JWT
JWT_SECRET=your-super-secret-jwt-key
JWT_REFRESH_SECRET=your-super-secret-refresh-key

# App
NODE_ENV=production
PORT=3000
FRONTEND_URL=https://yourdomain.com

# 결제 (나이스페이 - 필요 시)
NICEPAY_CLIENT_ID=your_client_id
NICEPAY_SECRET_KEY=your_secret_key
NICEPAY_API_URL=https://api.nicepay.co.kr/v1
```

### 4. 빌드 설정
Railway는 자동으로 `package.json`의 `build` 스크립트 실행:

```json
{
  "scripts": {
    "build": "nest build",
    "start:prod": "node dist/main"
  }
}
```

## ⚙️ 프로덕션 체크리스트

### app.module.ts 설정 확인
```typescript
TypeOrmModule.forRoot({
  // ...
  synchronize: process.env.NODE_ENV !== 'production', // ✅ 프로덕션: false
  logging: false, // ✅ 프로덕션: false
})
```

### main.ts 설정 확인
```typescript
// CORS 설정
app.enableCors({
  origin: process.env.NODE_ENV === 'production'
    ? process.env.FRONTEND_URL || 'https://yourdomain.com'
    : '*',
  credentials: true,
});

// ValidationPipe
app.useGlobalPipes(new ValidationPipe({
  whitelist: true,
  forbidNonWhitelisted: true,
  transform: true,
}));

const port = process.env.PORT || 3000;
await app.listen(port);
```

## 🐛 자주 발생하는 문제

### 1. DB 연결 오류
```
Error: ER_ACCESS_DENIED_ERROR: Access denied for user
```

**해결책**:
- Railway 환경변수 확인 (`MYSQLHOST`, `MYSQLUSER`, `MYSQLPASSWORD`)
- app.module.ts의 환경변수 우선순위 패턴 확인

### 2. JWT 에러
```
Error: secretOrPrivateKey must have a value
```

**해결책**:
- `JWT_SECRET` 환경변수 설정 확인

### 3. CORS 에러
```
Access to fetch at 'https://api.example.com' from origin 'https://app.example.com' has been blocked by CORS policy
```

**해결책**:
- main.ts의 CORS origin 설정 확인
- `credentials: true` 설정 확인

### 4. Migration 에러
```
Error: Table 'users' doesn't exist
```

**해결책**:
- `synchronize: true`로 임시 변경 (테스트 환경에서만)
- 또는 Migration 파일 생성 및 실행

### 5. Port 에러
```
Error: listen EADDRINUSE: address already in use :::3000
```

**해결책**:
```bash
# 포트 사용 중인 프로세스 종료 (Linux/Mac)
lsof -i :3000
kill -9 <PID>

# Windows
netstat -ano | findstr :3000
taskkill /PID <PID> /F
```

## 📊 모니터링 (선택)

### Sentry 통합 (에러 추적)
```bash
npm install @sentry/node
```

```typescript
// main.ts
import * as Sentry from '@sentry/node';

Sentry.init({
  dsn: process.env.SENTRY_DSN,
  environment: process.env.NODE_ENV,
});

// Global Exception Filter
app.useGlobalFilters(new SentryExceptionFilter());
```

## 🔄 CI/CD (선택)

### GitHub Actions
```yaml
# .github/workflows/deploy.yml
name: Deploy to Railway

on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Install Railway
        run: npm install -g @railway/cli
      - name: Deploy
        run: railway up
        env:
          RAILWAY_TOKEN: ${{ secrets.RAILWAY_TOKEN }}
```
