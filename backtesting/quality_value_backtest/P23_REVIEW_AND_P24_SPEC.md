## 2. 불합격 원인 분석 — ATR 스탑 단독 원인

### 팩터 알파는 OOS에서도 작동 중

```
2022: -7.82%   (SPY -18.1% 대비 방어. 팩터 선별 정상 작동)
2023: +15.03%  (회복 구간 수익 포착. 선별력 확인)
```

전략의 핵심인 Quality + Value + Momentum + Growth Filter는 **OOS에서도 검증**됐습니다.

### ATR 스탑이 2024~2025 수익을 완전히 소거

```
P22-A 기준   P23 OOS    차이
2024: +13.87%  →  -0.59%   -14.46%p
2025: +17.59%  →  -0.11%   -17.70%p

OOS ATR 청산율: 56.4%  (목표 < 30%)
```

2024년 AI 랠리, 2025년 지속 상승 구간에서 일봉 ATR × 2.5 스탑이 상승 추세 내 정상 조정에 반응하여 **강세 포지션을 반복 조기 청산**했습니다.

**이것은 이미 두 번 관찰된 패턴입니다.**

```
1차 관찰 (P21 초기 실험):
  ATR×2.5 스탑 → CAGR ~2.5% (베이스라인 11.62% 대비 붕괴)
  원인: "월간 전략의 자연 변동폭과 스탑이 충돌"
  조치: 스탑 완화 또는 제거 권고

2차 관찰 (P23 OOS):
  ATR×2.5 스탑 → OOS CAGR 1.58%
  원인: 동일. 상승장에서 스탑이 알파를 소거

결론: ATR 스탑 × 2.5는 이 전략에 구조적으로 부적합.
      월간 리밸런싱 전략에 일봉 단기 스탑을 적용하면
      시장이 상승하든 하락하든 반드시 손실이 발생.
```

## 3. P24 개발 지시서 — ATR 스탑 제거

### 3-1. 결정: ATR 인트라-피리어드 스탑 완전 제거

```
제거 대상:
  - stop_loss   = entry_price - ATR × 2.5
  - take_profit = entry_price + ATR × 6.0
  - update_trailing_stop() 호출부

유지 대상:
  - MAX_ATR_RATIO = 0.05 (진입 거부 필터)
    → 과고변동 종목 진입 자체를 막는 것은 유효
    → 진입 이후 스탑은 제거
```

**진입 후 청산 시점: 월간 리밸런싱 날짜만**

```python
# 변경 후 청산 로직 (단순화)
def should_close(position, current_date, rebalance_date):
    """
    청산 조건: 다음 리밸런싱 날짜에 해당 종목이 top_pct에서 탈락한 경우만.
    인트라-피리어드 스탑/익절 없음.
    """
    return current_date == rebalance_date and position.symbol not in new_portfolio
```

### 3-2. 근거 — 팩터 전략의 수익 구조

```
월간 리밸런싱 팩터 전략의 알파 발생 메커니즘:
  1. 선별 → 우량+저평가+상승추세 종목 진입
  2. 보유 → 시장의 가격 반영까지 수개월 대기 (이것이 알파)
  3. 청산 → Score 탈락 시 (더 좋은 종목으로 교체)

ATR 스탑이 이 구조를 파괴하는 방식:
  Step 2에서 정상적인 가격 변동에 반응해 강제 조기 청산
  → 가격 반영 과정이 완료되기 전에 포지션 종료
  → 알파 미실현

비유: 씨앗을 심고 일주일 만에 뽑아보는 것과 같음
      성장할 시간을 주지 않으면 수확 불가
```

### 3-3. P24 합격 기준

ATR 스탑 제거 후 P23 OOS 구간(2022~2026) 재실행 기준:

| KPI | 합격 기준 | P23 OOS (스탑 있음) | P22-A 참고 |
|-----|---------|----------------|----------|
| OOS CAGR | ≥ 10% | 1.58% | 13.41% |
| OOS Sharpe | ≥ 0.50 | 0.119 | 0.810 |
| OOS ATR 청산율 | 0% | 56.4% | — |
| 2024 수익률 | ≥ +10% | -0.59% | +13.87% |

### 3-4. 보고서 포함 항목

```
1. IS / OOS CAGR, Sharpe, MDD (스탑 제거 후)
2. OOS 연도별 수익률 (2022~2026 전체)
3. ATR 진입 거부 필터 효과 (MAX_ATR_RATIO=0.05 유지 확인)
   → 진입 거부된 종목 수 및 비율
4. 2022년 손실 수치 (팩터 방어력 재확인)
```

## 4. 전략 최종 구조 (P24 이후 확정판)

P24 완료 시 전략의 최종 구조입니다.

```
Layer 1 — 유니버스 필터
  - 가격 ≥ $5, ADV ≥ $2M, 시총 ≥ $200M
  - MAX_ATR_RATIO ≤ 0.05 (진입 거부)
  - 금융지주, 리츠 제외

Layer 2 — 팩터 점수 (0~100점)
  - Quality  35pt: F-Score + ROE + FCF + Accruals
  - Value    40pt: EV/EBITDA + P/FCF + P/B (섹터 상대)
  - Momentum 25pt: 12-1 가격 모멘텀

Layer 3 — Value Trap 하드 필터
  - ROE_2yr > -0.02 (경기순환: > -0.10)
  - FCF_2yr > -0.02 (경기순환: > -0.05)
  - Debt/Equity < 3.0
  - Rev_CAGR_3yr ≥ -0.05

Layer 4 — 포트폴리오 구성
  - top_pct = 10%, 섹터 최대 25%, 종목 최대 5%
  - 동일 비중 (또는 Score 비례 가중 — P24에서 재검토 가능)

Layer 5 — 청산 (단순화)
  - 월말 리밸런싱에서 Score 탈락 종목만 청산
  - 인트라-피리어드 스탑/익절 없음
```
