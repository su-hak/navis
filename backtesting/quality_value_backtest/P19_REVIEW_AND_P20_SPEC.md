## 2. 데이터 제약 사항 및 처리 방침

### 제약 1 — 일봉 캐시 기간 부족

```
현황:  일봉 캐시 2020-07-27부터만 존재 → 백테스트 기간 약 5.5년
스펙:  2016-01-01 ~ 2026-01-01 (10년)
영향:  2016~2019 일반 상승장 구간 검증 누락
```

**처리 방침:** P23 Walk-Forward 준비를 위해 데이터 확장을 P20과 **병행** 진행합니다. 전 종목을 한 번에 수집할 필요는 없습니다. 현재 `top_pct=10%` 편입 이력 종목을 우선 대상으로 2016-01-01부터 소급 수집하십시오.

```bash
# 수집 대상: 최근 6개월 포트폴리오 편입 이력 종목
# 수집 기간: 2016-01-01 ~ 2020-07-26 (소급)
# 수집 도구: 기존 yfinance 수집기 또는 데이터 수집 파이프라인
```

**현 단계 블로킹 여부:** 블로킹 아님. P23에서 공식 검증 예정.

---

### 제약 2 — min_composite_score 임시 하향 (25 적용)

```
스펙 기준:  min_composite_score = 55
임시 적용:  min_composite_score = 25

원인:  PEAD(0~13점), 자사주 매입(0~5점) 미구현
       → 현재 이론 최대점수 = 100 - 13 - 5 = 82점
       → 55 컷오프 적용 시 통과 종목 6개로 분산 불가
```

**처리 방침:** P20 완료(PEAD + 자사주 통합) 후 이론 최대점수가 100점으로 복원됩니다. 그 시점에 55 컷오프를 적용하되, **반드시 통과 종목 수를 먼저 확인**하고 목표 보유 범위(40~60종목)가 확보되는 수준에서 최종 확정하십시오. 단계적 상향이 필요하다면 40 → 50 → 55 순서로 검증합니다.

## 3. P19 성과 분석 — 퀀트 해석

### 긍정 신호

```
CAGR   8.98% → 15.50%  : P18 기준선 대비 +6.5%p, 약 두 배 개선
Sharpe 0.48  → 0.815   : 실전 운용 가능 수준(≥0.8) 최초 진입
MDD    28.81% → 20.97% : 약 8%p 개선
```

Multi-Factor Scoring이 단일 F-Score 대비 유의미하게 작동하고 있습니다. 전략 방향이 검증되었습니다.

---

### 주의 사항 — SPY 초과수익 +0.95%p

SPY 초과수익이 +0.95%p로 매우 얇습니다. 이유는 다음과 같습니다.

```
백테스트 구간: 2020-07 ~ 2026-01
이 구간 특성: 코로나 반등 + 유동성 장세 + AI 랠리가 모두 포함
              → 역사상 SPY 자체 성과가 가장 강했던 5년 중 하나
결론:         이 구간에서 +0.95%p는 일반 구간에서 SPY 언더퍼폼
              가능성을 시사함
```

**P20 PEAD 통합이 이 문제를 해결하는 핵심입니다.** PEAD는 이 전략에서 가장 기대 알파가 큰 팩터(+2~4%p)입니다. P20 완료 후 SPY 초과수익 +3%p 이상이 확인되어야 전략이 실전 운용 수준에 진입합니다.

### 4-2. Week 3 — PEAD 데이터 파이프라인 (1순위)

#### 수집 대상

| 항목 | 내용 |
|------|------|
| 컨센서스 EPS | 어닝 발표 전 애널리스트 컨센서스 중간값 |
| 실제 발표 EPS | 어닝 발표 결과값 |
| 발표일 | 장 전(BMO) / 장 후(AMC) 구분 포함 |
| 애널리스트 수 | 컨센서스 산출에 사용된 인원 수 |

#### 수집 품질 기준

```python
MIN_SURPRISE_PCT = 0.03   # 3% 미만 서프라이즈는 추정 오차 범위로 간주 → 제외
MIN_ANALYSTS     = 2      # 애널리스트 1명 추정치는 신뢰도 부족 → 제외
```

#### 저장 스키마

```
저장 경로: cache/earnings/{SYMBOL}_earnings.parquet

컬럼:
  symbol        : str    — 종목 심볼
  report_date   : date   — 어닝 발표일
  period        : str    — 해당 분기 (예: "2024Q1")
  actual_eps    : float  — 실제 발표 EPS
  consensus_eps : float  — 컨센서스 EPS (중간값)
  surprise_pct  : float  — (actual - consensus) / |consensus|
  n_analysts    : int    — 컨센서스 산출 애널리스트 수
```

#### calc_pead_score() 구현

스텁이 구현된 상태이므로 아래 로직을 완성하십시오.

```python
def calc_pead_score(symbol, as_of_date, earnings_cache, lookback_days=90):
    """
    최근 lookback_days 이내 어닝 서프라이즈 발생 시 점수 부여.
    서프라이즈가 클수록, 발표일로부터 가까울수록 고점.
    반환값: 0 ~ 13점
    """
    recent = earnings_cache.get_recent(symbol, as_of_date, lookback_days)
    if not recent or abs(recent.surprise_pct) < MIN_SURPRISE_PCT:
        return 0.0

    # 경과일 역가중: 발표 직후 = 1.0, lookback_days 경과 = 0.0
    days_elapsed  = (as_of_date - recent.report_date).days
    recency_weight = max(0.0, 1.0 - days_elapsed / lookback_days)

    # 서프라이즈 크기 클리핑 후 정규화
    raw_score = np.clip(recent.surprise_pct, -1.0, 1.0) * recency_weight  # -1 ~ 1
    return ((raw_score + 1.0) / 2.0) * 13.0  # 0 ~ 13점
```

```
수집 방법 우선순위:
  1순위: SEC EDGAR 차단 해제 시 8-K 공시에서 직접 수집
  2순위: Yahoo Finance buyback 데이터
  3순위: 이번 P20에서는 0점 처리 후 P21 또는 별도 태스크로 이관

저장 경로: cache/buybacks/{SYMBOL}_buybacks.parquet
컬럼: symbol | announce_date | amount_usd | program_total_usd
```

### 4-4. Week 4 — 팩터 통합 및 백테스트

#### 통합 순서

```
1. calc_pead_score() 완성 확인
2. Momentum Score에 PEAD 통합
   momentum_score = calc_momentum_12_1_score() + calc_pead_score()  # 12 + 13 = 25점
3. 자사주 수집 완료 시 Catalyst Score에 통합
   catalyst_score = calc_insider_score() + calc_buyback_score()     # 10 + 5 = 15점
4. 전체 백테스트 재실행 (동일 파라미터: top_pct=10%)
5. min_composite_score 55 적용 후 통과 종목 수 확인
   - 40종목 이상: 55 확정
   - 40종목 미만: 50 → 45 순으로 조정, 팀장 보고 후 확정
```

#### P20 보고서 포함 항목

보고서 제출 시 다음 항목을 반드시 포함하십시오.

```
1. PEAD 유무별 성과 비교
   - PEAD 제외 (P19 기준)  vs  PEAD 포함 (P20)
   - CAGR, Sharpe, SPY 초과수익 차이

2. 연도별 수익률 (2020~2026)
   - 특히 2022년(베어마켓) 손실 수치

3. min_composite_score 조정 결과
   - 55 적용 시 통과 종목 수
   - 채택 컷오프 값 및 근거

4. 어닝 서프라이즈 데이터 커버리지
   - 전체 유니버스 대비 PEAD 데이터 존재 종목 비율
```
