## 3. 핵심 발견 정리

### 3-1. Value 40pt가 주 동력

```
Value 25 → 40으로 상향 단독 효과: +0.91%p CAGR
  - DVA: 손실 상위 10위에서 완전 제거
  - 2024~2025 성과 개선이 두드러짐
  - 팩터 제거 실험(+11.51%p)과 일관된 결과
```

### 3-2. 하드 필터 — 2022 방어 vs 2020 드래그 트레이드오프

```
2022 방어:  -10.33% → -9.06% (+1.27%p 개선)
2020 드래그: 2년 평균 ROE도 음수인 COVID 직격 경기순환주
             2020 반등 구간 일부 누락 불가피

판단: 이 트레이드오프는 허용 가능
     2020은 역사적 이례 이벤트, 2022 방어는 반복 가능한 구조적 개선
     필터 유지
```

### 3-3. CPB — 미해결 Value Trap

CPB(Campbell Soup)가 손실 상위에 잔류합니다. ROE와 FCF가 양수여서 현재 하드 필터를 통과하지만, 매출이 수년째 정체 또는 감소 중인 제로성장 방어주입니다. 이것이 P22에서 처리할 **성장 필터 트랩**입니다.

---

## 4. P22 개발 지시서 — 성장 필터 + 데이터 확장

P22의 목표는 두 가지입니다. CPB 유형 트랩 차단과 10년 데이터 확보입니다. 두 가지가 이후 모든 수치의 신뢰도를 결정합니다.

### 4-1. 성장 필터 추가 (CPB 트랩 차단)

```python
# 하드 필터에 추가
def passes_growth_filter(fundamentals) -> bool:
    """
    매출 구조적 감소 기업 제외.
    완전한 성장이 아닌 '최소 유지' 기준 — 보수적 설정.
    """
    rev_cagr_3yr = fundamentals.get("revenue_cagr_3yr")  # 3년 매출 CAGR

    if rev_cagr_3yr is None:
        return True  # 데이터 없으면 통과

    # 3년 누적 매출 감소가 -5% 초과 시 제외
    # CPB: 3년 매출 CAGR 약 -2~-3% → 제외
    # 경기순환 회복주: 회복 연도 매출 급증 → 통과
    return rev_cagr_3yr >= -0.05
```

**판단 기준:**

| 종목 유형 | 3yr 매출 CAGR | 필터 결과 |
|---------|------------|---------|
| CPB (Campbell Soup) | 약 -2~-3% | ❌ 제외 |
| 경기순환 회복주 (항공 2021) | +20%+ | ✅ 통과 |
| 안정 성장주 (MSFT) | +10%+ | ✅ 통과 |
| 저성장 방어주 (유틸리티) | +1~3% | ✅ 통과 (기준 이상) |

**기존 필터에 AND 조건으로 추가:**

```python
def passes_all_filters(fundamentals, sector) -> bool:
    return (
        passes_value_trap_filter(fundamentals, sector)  # ROE/FCF/DE
        and passes_growth_filter(fundamentals)           # 매출 성장 최소 유지
    )
```

### 4-2. 데이터 확장 — 최우선 병행 작업

이것이 현 단계에서 가장 임팩트가 큰 단일 작업입니다.

```
현재 백테스트 기간: 2020-07 ~ 2026-01 (5.7년)
목표 기간:         2016-01 ~ 2026-01 (10년)

2016~2019 구간 특성:
  - Value 팩터 알파가 현 기간보다 강했던 구간
  - COVID 왜곡 없는 정상 시장 사이클
  - Momentum 팩터도 안정적으로 작동
  - 이 4년이 추가되면 CAGR이 현재보다 높게 나올 가능성 큼

수집 우선 대상:
  최근 6개월 포트폴리오 편입 이력 종목 → 전체 유니버스 순
  일봉 parquet: 2016-01-01 ~ 2020-07-26 소급
```
