## 2. 2020년 +135% 원인 분석

이것은 버그가 아닙니다. 월간 리밸런싱 전략이 COVID 저점을 구조적으로 포착한 결과입니다.

```
2020년 타임라인:
  2020-01-31 리밸런싱: 정상 시장 기준 포트폴리오 구성
  2020-02~03:         COVID 급락. 손절 없음 → 포지션 그대로 보유
  2020-04-30 리밸런싱: 급락한 Quality+Value 종목들이 Score 최상위로 집중
                       → 대거 저점 매수 실행
  2020-05~12:         V자 반등 전 구간을 보유한 상태로 탑승

P22-A와의 차이:
  P22-A 시작: 2020-07-27 (반등이 이미 절반 완료된 시점)
  P22-B 시작: 2016-01-01 → 2020년 전 구간 포함
  → P22-A의 2020 수익: +8.20% (하반기만)
  → P22-B의 2020 수익: +135.26% (전체 V자 포착)
```

**결론:** 2020년은 월간 리밸런싱 전략이 역사상 가장 완벽한 저점 매수를 실행한 해입니다. 실제로 발생한 수익이지만, 이 조건이 재현될 확률은 매우 낮습니다. 이 1년이 10년 CAGR을 비정상적으로 끌어올리고, Sharpe 계산에서 분모(변동성)를 폭발시켜 0.436으로 만들었습니다.

## 3. 2020년 제외 재계산 — 실질 성과

2020년을 제외한 9개년 연도별 수익률 기준으로 실질 전략 성과를 계산합니다.

| 연도 | P22-B |
|------|-------|
| 2016 | +10.66% |
| 2017 | +14.78% |
| 2018 | **-6.17%** |
| 2019 | +25.21% |
| ~~2020~~ | ~~+135.26%~~ (제외) |
| 2021 | +22.27% |
| 2022 | **-20.76%** |
| 2023 | +15.91% |
| 2024 | -0.59% |
| 2025 | -0.11% |
| 2026 | -2.46% |

```
2020 제외 CAGR (9년, 추정):
  9개년 연환산 = ((1.1066×1.1478×0.9383×1.2521×
                   1.2227×0.7924×1.1591×0.9941×0.9989×0.9754)^(1/9)) - 1
  ≈ 8.5~9.5% CAGR (추정)

해석: 2020 제외 시 현재 5.7년 P22-A(13.41%)보다 낮음
     2022 -20.76%가 주요 드래그
```

## 4. 핵심 발견 — 2022년이 진짜 약점

```
P22-A (2020~): 2022년 손실 미확인 (2022 전 구간 포함 안 됨)
P22-B (2016~): 2022년 -20.76%

이 숫자가 중요한 이유:
  2022: 연준 급격한 금리 인상 (0.25% → 4.50%)
  → 고PBR 성장주 붕괴 (전략이 회피)
  → 그러나 고부채 Value주도 금리 부담으로 동반 하락
  → Quality+Value 선별이 2022에는 방어력을 발휘하지 못함

비교:
  SPY 2022: -18.1%
  전략 2022: -20.76% → SPY보다 더 나쁨
```

2018(-6.17%)과 2022(-20.76%)가 전략의 두 개 취약 연도입니다. 공통점은 금리 상승 구간입니다.

## 5. P22-A vs P22-B — 무엇을 기준으로 쓸 것인가

| 구분 | P22-A | P22-B |
|------|-------|-------|
| 기간 | 2020~2026 (5.7년) | 2016~2026 (10년) |
| CAGR | 13.41% | 14.44% |
| Sharpe | **0.810** | 0.436 |
| 2020 효과 | 제외됨 | 포함 (135%) |
| 금리 상승 구간 | 2022 일부 | 2018+2022 전체 |
| 대표성 | 낙관적 (COVID 회복 구간) | 현실적 (완전 사이클 포함) |

**두 결과 모두 맞습니다. 해석이 다른 것입니다.**

```
P22-A: "2020 이후 정상 운용 시 기대 성과"
P22-B: "전체 시장 사이클 포함 장기 성과"

P23 Walk-Forward 기준: P22-B를 사용
이유: Walk-Forward는 미래 성과를 추정하는 작업
     실제 운용에서는 2020 같은 이벤트를 만날 수도, 못 만날 수도 있음
     전체 사이클을 포함한 보수적 추정이 적합
```

## 6. P23 개발 지시서 — Walk-Forward 최종 검증

### 6-1. 목적

지금까지 모든 파라미터를 동일 데이터로 최적화했습니다. 이것이 과적합인지 아닌지를 확인하는 것이 P23입니다. 미래 구간에서도 작동하는 전략인지를 최종 판정합니다.

### 6-2. 설계

```
In-Sample  (파라미터 확정): 2016-01-01 ~ 2021-12-31 (6년)
Out-of-Sample (검증):       2022-01-01 ~ 2026-01-01 (4년)

규칙:
  In-Sample에서 현재 확정 파라미터를 그대로 고정
  Out-of-Sample은 추가 튜닝 없이 그대로 적용
  OOS 성과가 IS 대비 30% 이상 열화 시 과적합 판정
```

### 6-3. 확정 파라미터 (현재 기준)

P23에 사용할 파라미터 목록입니다. 변경 없이 고정합니다.

| 파라미터 | 확정값 | 결정 단계 |
|---------|--------|---------|
| `top_pct` | 10% | P19 |
| `min_composite_score` | 비례 (55점 목표) | P20 이후 |
| Value 배점 | 40점 | P21 |
| Quality 배점 | 35점 | P21 |
| Momentum 배점 | 25점 | P19 |
| `MAX_ATR_RATIO` | 0.05 | P21 |
| 하드 필터 ROE 기준 | -0.02 / -0.10 (일반/경기순환) | P21 |
| 성장 필터 | rev_cagr_3yr ≥ -0.05 | P22-A |

### 6-4. 합격 기준

| 구분 | KPI | 기준 |
|------|-----|------|
| In-Sample (2016~2021) | CAGR | ≥ 12% |
| In-Sample (2016~2021) | Sharpe | ≥ 0.60 |
| **Out-of-Sample (2022~2026)** | **CAGR** | **≥ 10%** |
| **Out-of-Sample (2022~2026)** | **Sharpe** | **≥ 0.50** |
| OOS vs IS 열화 | CAGR 비율 | OOS ≥ IS × 0.70 |

> OOS 2022~2026 구간에는 -20.76%인 2022년이 포함됩니다.
> 이 구간에서 CAGR ≥ 10%, Sharpe ≥ 0.50이면 전략이 실전 수준으로 검증됩니다.

### 6-5. 보고서 포함 항목

```
1. IS / OOS 각각의 CAGR, Sharpe, MDD
2. OOS 연도별 수익률 (2022, 2023, 2024, 2025)
3. 특히 2022 손실 수치 — 전략의 금리 상승 내성 확인
4. 과적합 판정 결과 (OOS/IS 비율)
```
