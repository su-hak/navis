## 3. P18-C 핵심 인사이트

### 3-1. MDD 개선 효과
```
P17-3A:  MDD 28.81%
P18-C:   MDD 25.21%  ← -3.60%p 개선
목표:    MDD ≤ 20%   ← 5.21%p 추가 개선 필요
```

**Catalyst + Momentum 조합의 MDD 개선 메커니즘:**
- Catalyst (내부자 매수): 가치 반등 확신 종목 선별 → 하락장 진입 억제
- Momentum (상위 30%): 최근 낙폭 큰 종목 제외 → "떨어지는 칼날" 차단
- 두 필터의 교집합: 재무 우량(F≥6) + 내부자 확신(Catalyst) + 상승 추세(Momentum)

### 3-2. 2020년 성과 차이
```
P18-B-Rev: 2020 +13.7%
P18-A:     2020 +8.7%
P18-C:     2020 +29.3%  ← 코로나 급반등 최대 포착
```
Catalyst + Momentum 조합이 코로나 저점 이후 반등 종목을 가장 잘 포착함.

### 3-3. 2025년 약점 (-10.5%)
```
P18-A: 2025 +2.6%
P18-C: 2025 -10.5%  ← 역방향 이탈
```
Momentum 필터가 2024년 고점 종목 편향 → 2025년 조정 시 집중 손실 발생.

## 4. 핵심 발견: 근본 병목

### 공통 문제: STOP_LOSS 40%+
```
모든 변형에서 STOP_LOSS 비율 37~45%
→ 약세장(2018, 2020, 2022) 손절이 CAGR 상승을 차단

P18-C: STOP_LOSS 140건 (40.0%) — 기준선과 동일
```

### 왜 Catalyst 필터가 CAGR을 개선하지 못했나?
1. **OpenInsider 데이터 한계**: 대형 공개 매수만 집계 → 소액/비공개 내부자 신호 누락
2. **Tier1 소수 (5~15%)**: 매달 Catalyst 종목은 F≥6 중 10-15%만 → 나머지는 Tier2(일반 선별)
3. **데이터 선행편향 없음**: 파일링 날짜 기준 point-in-time 정확 → 오히려 신호 지연 발생
4. **역방향 인과**: 내부자가 살 때 주가가 이미 바닥 → 손절선 -15%에 걸리는 경우 존재

## 5. OpenInsider vs SEC EDGAR 데이터 차이

| 항목 | SEC EDGAR (차단 중) | OpenInsider (사용) |
|------|------|------|
| 데이터 원천 | Form 4 원본 XML | Form 4 집계 |
| 커버리지 | 전체 내부자 | 주요 임원/이사 |
| 최소 금액 | 수동 필터 | 사이트 기본 필터 |
| 정확도 | 최고 | 양호 |
| 접근 여부 | ❌ 차단 | ✅ 정상 |

> **중요**: SEC EDGAR 원본 XML 데이터를 사용하면 P18-A 결과가 개선될 가능성 있음.  
> OpenInsider 데이터 한계로 인해 이번 P18-A/C 결과는 보수적 추정치.
