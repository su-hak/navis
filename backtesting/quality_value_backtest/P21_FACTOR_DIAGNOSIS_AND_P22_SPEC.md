## 2. 긴급 진단 작업 — 팩터 기여도 분리 테스트

### 2-1. 배경

Multi-Factor Score 구성:

| 팩터 | 배점 | 역할 |
|------|------|------|
| Quality | 35점 | F-Score + ROE + FCF + Accruals |
| Value | 25점 | EV/EBITDA + P/FCF + P/B (섹터 상대) |
| Momentum | 25점 | 12-1 가격 모멘텀 |
| Catalyst | 15점 | 내부자 순매수 |

**가설:** Value Factor(25점)가 2020~2026 구간에서 역선택을 유발하고 있습니다.

```
근거:
  이 기간 최고 수익 종목 (NVDA +1,800%, MSFT +200%, AAPL +150%)은
  전통 밸류에이션 지표(EV/EBITDA, P/B)로는 모두 "고평가" 구간
  → Value 점수가 낮음 → 포트폴리오에서 제외 또는 언더웨이트
  → 시장 최고 수익 종목들을 구조적으로 놓침
```

### 2-2. 팩터 제거 실험 (Ablation Test)

4가지 백테스트를 순서대로 실행하십시오. 각 실험은 해당 팩터의 배점을 0으로 고정하고 나머지 팩터로만 점수를 산출합니다. 파라미터는 P19 클린 기준(top_pct=10%, min_score 비례 조정)을 유지합니다.

| 실험 | 제거 팩터 | 나머지 배점 합계 |
|------|---------|--------------|
| T1 | Quality 제거 | Value+Momentum+Catalyst = 65점 만점 |
| T2 | **Value 제거** | Quality+Momentum+Catalyst = 75점 만점 |
| T3 | Momentum 제거 | Quality+Value+Catalyst = 75점 만점 |
| T4 | Catalyst 제거 | Quality+Value+Momentum = 85점 만점 |

```python
# 구현 방법: 각 실험에서 해당 팩터 계산 결과를 0으로 오버라이드
# 예시 (T2 Value 제거):
composite_score = quality_score + 0 + momentum_score + catalyst_score
#                                 ↑ Value를 0으로 고정
```

### 2-3. 판독 기준

```
P19 클린 베이스라인: CAGR 11.80%

특정 팩터 제거 후 CAGR이 상승  → 해당 팩터가 현 구간에서 알파를 훼손 중
특정 팩터 제거 후 CAGR이 하락  → 해당 팩터가 실질 기여 중

판단 기준:
  +0.5%p 이상 상승: 해당 팩터 가중치 대폭 축소 검토
  -0.5%p 이상 하락: 해당 팩터 핵심 기여자로 확정
  ±0.5%p 이내:     중립 (데이터 기간 짧아 노이즈 가능)
```

## 3. P22 Market Regime Gate — 즉시 병행 착수

팩터 진단과 무관하게 P22를 병행 착수합니다. Regime Gate는 팩터 선별력과 독립적으로 작동하며, 2022년 손실 방어 효과가 명확하기 때문입니다.

### 3-1. 근거

```
현재 전략 2022 손실: 약 -10% (추정)
SPY 2022 손실:      -18.1%

Market Regime Gate 기대 효과:
  Bear 진입 시 포지션 50% 현금 전환
  → 2022 손실 -10% → -5% 수준으로 완화
  → CAGR에 +1.0~1.5%p 기여 예상

이것은 팩터 선별력과 무관한 독립 알파
```

### 3-2. 레짐 분류 로직

```python
# 추가 위치: strategy_engine/market_regime/ 기존 모듈 연동

def classify_regime(spy_df: pd.DataFrame, as_of_date) -> str:
    close  = get_price(spy_df, as_of_date, "close")
    ma200  = sma(spy_df, as_of_date, period=200)
    ma50   = sma(spy_df, as_of_date, period=50)

    if close > ma200 and ma50 > ma200:
        return "BULL"      # 100% 주식
    elif close < ma200:
        return "BEAR"      # 50% 주식 / 50% 현금
    else:
        return "NEUTRAL"   # 75% 주식 / 25% 현금
```

### 3-3. 포지션 정책

| 레짐 | 주식 노출 | 목표 보유 종목 수 |
|------|---------|--------------|
| BULL | 100% | top_pct 기준 전체 |
| NEUTRAL | 75% | × 0.75 |
| BEAR | 50% | × 0.50 |

### 3-4. 전환 처리 규칙

```
BULL → NEUTRAL, NEUTRAL → BEAR:  5거래일에 걸쳐 점진 축소
BULL/NEUTRAL → BEAR (급락):      3거래일 내 완료 (방어 속도 우선)
BEAR → NEUTRAL → BULL:           10거래일에 걸쳐 점진 확대 (재진입 신중)
```

### 3-5. P22 합격 기준

| KPI | 합격 기준 | 현재 (P19 클린) |
|-----|---------|--------------|
| CAGR | ≥ 13.0% | 11.80% |
| 2022 손실 | > -7% | 약 -10% (추정) |
| MDD | ≤ 18% | -20.19% |
| Sharpe | ≥ 0.70 | 0.647 |

## 4. 팩터 진단 결과에 따른 분기 처리

팩터 제거 실험 결과에 따라 다음 분기로 진행합니다.

### 분기 A — T2(Value 제거)에서 CAGR 상승 시

```
조치: Value Factor 가중치 25점 → 5점으로 대폭 축소
      축소분(20점)을 Momentum에 배분 (25점 → 45점)
      이유: 2020~2026 구간은 성장주 모멘텀 시대
            Value는 10년 사이클에서는 유효하나 현 구간 역효과
근거: 팩터 가중치는 고정값이 아님
      시장 레짐에 따라 조정하는 것이 표준 퀀트 관행 (Regime-Aware Factor Weighting)
```

### 분기 B — T3(Momentum 제거)에서 CAGR 상승 시

```
조치: 12-1 모멘텀을 단기 모멘텀(3-1)으로 교체 테스트
      이유: 12개월 모멘텀이 과거 수익 종목을 고점 진입시킬 가능성
```

### 분기 C — 4개 실험 모두 ±0.5%p 이내 시

```
의미: 현재 팩터 조합 자체는 무난하나 5.7년 데이터 부족으로 판단 불가
조치: 팩터 조정 보류, P22 완료 후 10년 데이터 확보를 최우선으로 전환
      데이터 없이 팩터를 계속 조정하는 것은 과적합 위험
```

## 5. 세 옵션 A/B/C 처리 방침

개발팀이 제안한 세 옵션은 팩터 진단 결과 이후로 보류합니다.

| 옵션 | 내용 | 처리 |
|------|------|------|
| A (복합점수 비례 사이징) | 팩터 진단 후 진행 | ⏳ 대기 |
| B (top-pct 5% 집중) | 팩터 진단 후 진행 | ⏳ 대기 |
| C (P22 레짐 필터) | **즉시 착수** | ✅ 본 문서 3절 |

옵션 A와 B는 팩터 선별력이 충분할 때 의미가 있습니다. Value Factor가 역선택 중이라면 집중도를 높여도 악화될 수 있습니다. 진단 먼저, 집중 나중입니다.
