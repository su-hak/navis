## 3. --no-atr-stops 기본값 전환 승인

**승인합니다.** `--no-atr-stops`를 기본값으로 변경하십시오.

```python
# 변경 전
ATR_STOP_ENABLED  = True
STOP_ATR_MULT     = 2.5
PROFIT_ATR_MULT   = 6.0

# 변경 후
ATR_STOP_ENABLED  = False   # 인트라-피리어드 스탑 비활성화
# STOP_ATR_MULT, PROFIT_ATR_MULT 파라미터는 코드에 잔류 가능
# (향후 단기 전략 적용 가능성을 위해 삭제하지 않아도 됨)

# 유지
MAX_ATR_RATIO = 0.05        # 진입 거부 필터는 그대로 유지
```

## 4. 10년 최종 수치 확정 실행 지시

**예**: 전체 10년(2016~2026) 기준 최종 수치를 실행하십시오.

단, 보고서에 두 수치를 반드시 병기하십시오.

```
수치 A (전체 10년):  2016-01-01 ~ 2026-01-01
수치 B (2020 제외):  2016-2019 + 2021-2026 (COVID 이벤트 연도 제외)

이유:
  수치 A — 전략이 실제로 경험할 수 있는 모든 상황 포함 (공식 수치)
  수치 B — COVID +135% 없이 반복 가능한 장기 기대치 (현실적 수치)
  두 수치의 차이가 크면 2020 이벤트 의존도를 의사결정에 고려
```

보고서 포함 항목:

```
1. 전체 10년 CAGR, Sharpe, MDD, SPY 대비 초과수익
2. 2020 제외 9개년 동일 지표
3. 연도별 수익률 전체 (2016~2026)
4. 손실 연도: 2018, 2022 수치 강조
```

## 6. 현재 성과 위치 및 다음 과제

### 검증된 성과 (OOS 2022~2026 기준)

```
CAGR:   12.16%
Sharpe: 0.688
MDD:    -14.16%
SPY 대비: +0~2%p (추정, SPY 동기간 ~11~12%)
```

### Phase 1 목표 대비

```
목표:     CAGR 18%, Sharpe 0.8, MDD < 18%
현재 OOS: CAGR 12.16%, Sharpe 0.688, MDD -14.16%
갭:       CAGR +5.84%p, Sharpe +0.112
```

MDD는 목표 달성. CAGR과 Sharpe는 미달.

### 잔여 갭 해소 경로

| 경로 | 기대 기여 | 조건 |
|------|---------|------|
| 10년 전체 수치 확정 | 수치 안정화 | P24 완료 후 즉시 |
| Catalyst 복원 (Form4 클린 데이터) | +0.5~1.5%p | 유료 소스 or SEC 해제 |
| 페이퍼 트레이딩 6개월 | 실전 검증 | 전략 확정 후 |
| 레버리지 1.3x | × 1.3 배율 | Sharpe ≥ 0.8 + 6개월 트랙레코드 |

```
레버리지 1.3x 시나리오:
  CAGR 12.16% × 1.3 = 15.8%
  Sharpe 0.688 (레버리지로 불변)
  MDD  14.16% × 1.3 = 18.4%
  → 목표 18%에 근접, MDD는 허용 범위 내
```
