## 3. 이정표 확인

### Sharpe 0.810 — 실전 운용 진입 기준 최초 달성

```
Sharpe 0.8 이상의 의미:
  - 레버리지 1.3x 적용 시 예상 CAGR: 13.41% × 1.3 = 17.4%
  - 레버리지 MDD:                   17.51% × 1.3 = 22.8%
  - 레버리지 1.3x가 처음으로 현실적 선택지가 됨

단, 현재 5.7년 샘플 기반임을 반드시 고려할 것.
10년 데이터 Walk-Forward 통과 후 레버리지 논의 시작.
```

### SPY 갭 절반 축소

```
P19: SPY 대비 -3.20%p
P22: SPY 대비 -1.16%p
개선: +2.04%p

남은 갭: +1.16%p (SPY 동등) + 목표 초과 +3%p = 총 +4.16%p 필요
해소 경로: 2016~2019 데이터 확보가 핵심
```

## 4. P22-B — 데이터 확장 (선행 조건 미충족)

### 현황

```
문제: 일봉 캐시가 2020-07-27부터만 존재
      --start 2016-01-01 지정해도 첫 리밸런싱이 2020-07-31로 고정
      → Exp C/D 결과가 A/B와 동일한 이유

선행 조건: Alpaca API로 2016-01-01 ~ 2020-07-26 일봉 백필 필요
```

### Alpaca 백필 지시

P22_SPEC.md에 수집 방법이 포함되어 있습니다. 우선순위를 최상으로 설정하십시오.

```
수집 대상: 유니버스 전체 종목
수집 기간: 2016-01-01 ~ 2020-07-26 (약 4.6년)
저장 경로: 기존 일봉 parquet와 동일 구조로 병합
예상 소요: 반일~1일 (Alpaca 무료 요금제 속도 제한 기준)

우선 수집 대상: 최근 포트폴리오 편입 이력 종목 → 전체 순으로 확장
```

### P22-B 실행 후 기대

```
2016~2019 특성:
  - Value 팩터 알파가 현 기간 대비 강함 (Growth 버블 전)
  - Momentum 팩터 안정적 작동
  - COVID 왜곡 없는 정상 사이클

기대 CAGR 변화:
  10년 백테스트 CAGR ≥ 현재 13.41% 가능성 높음
  보수적 추정: +1.0~1.5%p → 14.4~14.9%
  낙관적 추정: +1.5~3.0%p → 14.9~16.4%
```

## 5. CPB 잔류 처리

CPB는 인수합병으로 인해 매출 성장 필터를 통과하고 있습니다. M&A로 인한 일시적 매출 팽창이 구조적 하락을 가립니다. 현 단계에서 개별 종목 예외 처리는 과적합 위험이 있으므로 **보류**합니다.

```
처리 방침: P22-B (10년 백테스트) 이후 CPB가 여전히 손실 상위에 있으면
           M&A 조정 매출 성장률 필터 추가 검토.
           현 5.7년 샘플에서 단일 종목 기준 필터 추가는 과적합.
```
