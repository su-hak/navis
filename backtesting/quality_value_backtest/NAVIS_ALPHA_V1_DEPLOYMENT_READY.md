## 4. 개발 과정 핵심 발견 — 팀 공유

향후 전략 수정 또는 파생 전략 개발 시 반드시 참조해야 할 발견입니다.

### 절대 재도입 금지 — ATR 인트라-피리어드 스탑

```
근거 1 (P21): ATR×2.5 스탑 적용 시 CAGR 11.62% → 2.5%로 붕괴
근거 2 (P23): OOS 2022-2026에서 스탑 청산율 56.4%, CAGR 1.58%
근거 3 (P24): 스탑 제거가 2022 하락 방어까지 개선 (-7.82% → -5.03%)
              스탑이 상승장 알파 소거 + 하락장 저점 청산을 동시에 유발

결론: 월간 리밸런싱 팩터 전략에 일봉 단기 스탑은 구조적으로 부적합.
      어떤 시장 환경에서도 재도입하지 않는다.
```

### Value 팩터가 핵심 알파 소스

```
팩터 제거 실험 결과:
  Value 제거 시 CAGR 11.80% → 0.29% (전략 붕괴)
  Quality 제거: -5.91%p
  Momentum 제거: -0.69%p
  Catalyst 제거: 0.00%p

Value > Quality >> Momentum > Catalyst 순서
Value 배점을 25 → 40으로 상향한 것이 핵심 개선
```

### Market Regime Gate는 이 전략에 역효과

```
실험 결과: SPY 200MA 게이트가 2022 손실을 -10.33% → -16.73%로 악화
원인: Quality+Value 선별이 이미 자연 방어력 제공
      200MA 신호 후행으로 저점 매도 + 반등 후 재진입 반복
결론: 팩터 전략에 시장 타이밍 레이어 추가는 이 전략에 비적합
```

## 5. 다음 단계 로드맵

### Phase A — 페이퍼 트레이딩 (즉시 시작, 6개월)

```
목적: 백테스트와 실전 간 갭 측정
      슬리피지, 시가 집행 오차, 데이터 지연 영향 확인
기간: 2026-05 ~ 2026-11
기준: 페이퍼 트레이딩 월 수익률이 백테스트 대비 -3%p 이내면 실전 진입 승인
```

### Phase B — Catalyst 복원 (병행)

```
목적: Catalyst 0점 → 유효 신호 복원 (+0.5~1.5%p 기대)
조건: Form4 원본 데이터 (SEC EDGAR 차단 해제 or FMP $14/월)
현황: SEC EDGAR Akamai 차단 지속. 해제 즉시 실행.
```

### Phase C — 실전 소액 운용 (Phase A 완료 후)

```
조건: 페이퍼 트레이딩 6개월 통과
자본: 소액 ($10,000~$50,000) 시작
목표: 실전 트랙레코드 6개월 확보
```

### Phase D — 레버리지 검토 (Phase C 완료 후)

```
레버리지 1.3x 진입 조건:
  ① Sharpe ≥ 0.8 (현재 OOS 0.688, 2020 제외 ~0.86)
  ② 실전 트랙레코드 6개월
  ③ 리스크팀 승인

레버리지 1.3x 예상 성과:
  CAGR: 12.16% × 1.3 = 15.8%
  MDD:  14.16% × 1.3 = 18.4%
  목표 18%까지 -2.2%p (Catalyst 복원 시 달성 가능)
```
